FAQ

Часто задаваемые вопросы о DS Motier. Если не нашли ответ - создайте Issue на GitHub.

Что такое DS Motier?

DS Motier - это Discord-бот с открытым исходным кодом, который автоматизирует создание и управление структурой Discord-сервера. Вместо того чтобы вручную создавать каждый канал, категорию и роль, вы описываете желаемую структуру в текстовом файле на специальном языке DSL (Domain-Specific Language), и бот собирает сервер по этому шаблону.

Какие языки поддерживает DSL?

DSL использует английские ключевые слова (CATEGORY, CHANNEL, ROLE и т.д.), но названия каналов, ролей и содержимое могут быть на любом языке. Встроенной локализации интерфейса нет - бот общается на русском через слеш-команды.

Нужен ли опыт программирования?

Нет. DSL специально спроектирован так, чтобы быть понятным любому пользователю. Синтаксис минималистичен: блоки с фигурными скобками, атрибуты с @, переменные с $. Примеры в документации покрывают 99% случаев. Если вы умеете редактировать текстовый файл - вы уже умеете пользоваться DS Motier.

Какие права нужны боту на сервере?

Для полноценной работы боту требуется право Administrator. Если вы хотите ограничить права, минимально необходимый набор: Manage Channels, Manage Roles, Manage Messages, Kick Members, Ban Members, Create Instant Invite, Embed Links, Read Message History.

Может ли бот изменять существующий сервер?

Да. Команда /build анализирует текущую структуру сервера и применяет шаблон поверх неё. Бот создаст недостающие каналы и роли, но не удалит существующие и не тронет контент (сообщения, участников). Это делает /build безопасным для использования на уже работающих серверах.

Как обновить шаблон после изменений?

Просто отредактируйте .txt файл и снова выполните /build с обновлённым файлом. Бот применит изменения: добавит новые каналы/роли, обновит атрибуты существующих (например, цвет роли или slowmode канала). Удаление каналов или ролей из шаблона не удалит их с сервера - это сделано намеренно, чтобы избежать случайных потерь.

Что такое TEMP_VOICE и как это работает?

TEMP_VOICE (временные голосовые комнаты) - функция, позволяющая пользователям создавать собственные голосовые каналы по кнопке. Когда пользователь нажимает кнопку, создаётся новый голосовой канал с заданным префиксом. Канал автоматически удаляется, когда последний участник его покидает. Это удобно для клановых серверов, где игроки хотят иметь отдельные комнаты для своих групп.

Можно ли настроить несколько тикет-систем?

Да. Вы можете создать несколько блоков TICKET в разных категориях. Каждый будет иметь свою кнопку и свой канал для создания тикетов. Например, один TICKET для технической поддержки, другой - для жалоб на игроков.

Как добавить бота на сервер?
  1. Перейдите на Discord Developer Portal
  2. Создайте новое приложение и перейдите в раздел Bot
  3. Нажмите "Add Bot" и скопируйте токен
  4. В разделе OAuth2 → URL Generator выберите scope "bot" и permission "Administrator"
  5. Откройте сгенерированный URL и выберите сервер
Это бесплатно?

Да. DS Motier - проект с открытым исходным кодом под лицензией MIT. Вы можете бесплатно использовать, модифицировать и распространять бота. Единственное, что вам может понадобиться - это сервер для хостинга бота (например, VPS или Raspberry Pi).

Где я могу получить помощь?

Основной источник информации - документация на этом сайте. Если вы нашли баг или у вас есть предложение - создайте Issue на GitHub. Pull Requests приветствуются.
