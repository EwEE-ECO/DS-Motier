Documentation

DSL (Domain-Specific Language) v3.0 is a text-based format for describing Discord server structure. The DS Motier bot reads a .txt template and builds the server automatically: categories, channels, roles, forums, tickets, temporary voice channels.

Key Features

  • Categories, text channels, forums, stages, counters
  • Roles with permissions, colors, display settings
  • Ticket system and temporary voice channels
  • Button and reaction role assignment
  • Greetings, auto-messages, embeds
  • Variables $name
  • File includes via !INCLUDE
  • Access selectors @allow / @deny

Blocks

CATEGORY

Category

Groups channels. Can contain CHANNEL, FORUM, VOICE, STAGE, COUNTER, TEMP_VOICE.

CATEGORY "Информация" {
  CHANNEL #правила
  CHANNEL #новости
}

CATEGORY "Админ" @admin {
  CHANNEL #админ-чат
}

Selector @admin after the name restricts category visibility to that role.

CHANNEL

Text Channel

CHANNEL #общий
CHANNEL #правила { @slowmode 5 }
CHANNEL #админ { @deny @everyone @allow admin }

Attributes: @slowmode (seconds), selectors @allow/@deny.

FORUM

Forum

Forum channel with built-in threads. At least one THREAD is required inside.

FORUM "Поддержка" {
  THREAD баг-репорт
  THREAD вопрос
  @slowmode 30
}
THREAD

Forum Thread

THREAD баг-репорт
THREAD "тема с пробелами"

Single word - no quotes, multiple words - in double quotes.

STAGE

Stage (Event)

Voice channel for events.

STAGE "Текущий эфир"
STAGE "LIVE" { @topic "Обсуждаем обновление" }
COUNTER

Member Counter

A voice channel whose name displays the server member count.

COUNTER "👥 Участники: {count}"
COUNTER "🎧 В голосе: {count}"

{count} is replaced with the current member count.

ROLE

Role

ROLE "Модератор" {
  @color #5865F2
  @permissions kick_members, ban_members
  @display separate
  @mentionable true
}

ROLE "Новичок" { @color #808080 }

Attributes:

  • @color - HEX color
  • @permissions - comma-separated permission list
  • @display - separate / none
  • @mentionable - true / false
TICKET

Ticket System

Creates a channel with a ticket open button. Clicking creates a private channel for the user.

TICKET "Связаться с нами" {
  @category "Поддержка"
  @button 📩 Создать тикет
  @description "Мы ответим в ближайшее время"
}
TEMP_VOICE

Temporary Voice

User clicks a button - a temporary voice channel is created. Deleted when everyone leaves.

TEMP_VOICE "Создать комнату" {
  @category "Голосовые"
  @button 🔈 Создать
  @channel_prefix "Комната"
  @user_limit 10
}
EMBED

Embed Message

Sends a styled embed message to the specified channel on build.

EMBED #правила {
  @title "Правила сервера"
  @description "1. Уважайте друг друга\n2. Не флудите"
  @color #5865F2
  @footer "DS Motier"
}
BUTTON_ROLE

Button Roles

Assign roles by button click.

BUTTON_ROLE "Роли" {
  @channel #роли
  @description "Выберите игры"
  ROLE "CS:GO" 🎮
  ROLE "Valorant" 🔫
}
REACTION_ROLE

Reaction Roles

Assign roles by reacting to a message.

REACTION_ROLE "Уведомления" {
  @channel #реакции
  @description "Нажми на реакцию"
  REACTION "📢" анонсы
  REACTION "🎮" ивенты
}
AUTO_MESSAGE

Auto Message

Automatically sends a message to a channel on build.

AUTO_MESSAGE #общий {
  @content "Добро пожаловать!"
}

AUTO_MESSAGE #правила {
  @embed "Правила"
  @content "Ознакомьтесь выше"
}
WELCOME

Welcome

Greets new members in the specified channel.

WELCOME {
  @channel #общий
  @message "Добро пожаловать, {user}!"
}

{user} is replaced with the new member's mention.

!INCLUDE

File Includes

Allows splitting the template into multiple files.

!INCLUDE "base.txt"
!INCLUDE "roles/moderators.txt"

Variables

Variables let you reuse values in the template. Declared with $name = value.

$color_primary = #5865F2
$color_danger  = #ED4245
$prefix        = "!"
$admin_role    = "Администратор"

CATEGORY "Основное" {
  CHANNEL #общий { @allow $admin_role }
}

ROLE $admin_role { @color $color_primary }

Can be used anywhere in the template except string literals.

Access Selectors

Control visibility of channels and categories.

CHANNEL #админ-чат {
  @allow admin
  @deny @everyone
}

CATEGORY "VIP" @vip {
  CHANNEL #vip-чат
}
  • @allow role - grant access
  • @deny role - deny access
  • @everyone - reference to the @everyone role
  • Selector after CATEGORY applies to all nested channels

Examples

Minimal Template

CATEGORY "Основное" {
  CHANNEL #общий
  CHANNEL #оффтоп
}

ROLE "Модератор" { @color #5865F2 }

Full Template

@name "Мой сервер"

$color_main = #5865F2
$color_success = #57F287

!INCLUDE "base.txt"

CATEGORY "Информация" {
  CHANNEL #правила { @slowmode 5 }
  CHANNEL #новости
  CHANNEL #объявления { @allow admin }
}

CATEGORY "Общение" {
  CHANNEL #общий
  CHANNEL #оффтоп
  FORUM "Поддержка" {
    THREAD баг-репорт
    THREAD вопрос
    THREAD предложение
  }
}

ROLE "Модератор" color=$color_main {
  @permissions kick_members, ban_members
  @display separate
}

TICKET "Связаться с нами" {
  @category "Поддержка"
  @button 📩 Создать тикет
}

TEMP_VOICE "Создать комнату" {
  @category "Голосовые"
  @button 🔈 Создать
}

WELCOME {
  @channel #общий
  @message "Добро пожаловать, {user}!"
}
