FAQ

Frequently asked questions about DS Motier. If you didn't find an answer — create an Issue on GitHub.

What is DS Motier?

DS Motier is an open-source Discord bot that automates the creation and management of Discord server structure. Instead of manually creating every channel, category, and role, you describe your desired structure in a text file using the special DSL (Domain-Specific Language), and the bot builds the server from that template.

What languages does DSL support?

DSL uses English keywords (CATEGORY, CHANNEL, ROLE, etc.), but channel names, role names, and content can be in any language. There is no built-in interface localization — the bot communicates in Russian via slash commands.

Do I need programming experience?

No. DSL is specifically designed to be understandable by any user. The syntax is minimalistic: blocks with curly braces, attributes with @, variables with $. Examples in the documentation cover 99% of cases. If you can edit a text file — you already know how to use DS Motier.

What permissions does the bot need on the server?

For full functionality, the bot requires the Administrator permission. If you want to limit permissions, the minimum required set is: Manage Channels, Manage Roles, Manage Messages, Kick Members, Ban Members, Create Instant Invite, Embed Links, Read Message History.

Can the bot modify an existing server?

Yes. The /build command analyzes the current server structure and applies the template on top of it. The bot will create missing channels and roles, but will not delete existing ones or touch content (messages, members). This makes /build safe to use on already running servers.

How do I update the template after changes?

Simply edit the .txt file and run /build again with the updated file. The bot will apply changes: add new channels/roles, update attributes of existing ones (e.g., role color or channel slowmode). Removing channels or roles from the template will not delete them from the server — this is intentional to avoid accidental data loss.

What is TEMP_VOICE and how does it work?

TEMP_VOICE (temporary voice rooms) — a feature that allows users to create their own voice channels with a button. When a user clicks the button, a new voice channel with a specified prefix is created. The channel is automatically deleted when the last member leaves. This is useful for clan servers where players want separate rooms for their groups.

Can I set up multiple ticket systems?

Yes. You can create multiple TICKET blocks in different categories. Each will have its own button and its own channel for creating tickets. For example, one TICKET for technical support, another for player reports.

How do I add the bot to a server?
  1. Go to the Discord Developer Portal
  2. Create a new application and go to the Bot section
  3. Click "Add Bot" and copy the token
  4. In the OAuth2 → URL Generator section, select scope "bot" and permission "Administrator"
  5. Open the generated URL and select your server
Is it free?

Yes. DS Motier is an open-source project under the MIT license. You can freely use, modify, and distribute the bot. The only thing you might need is a server to host the bot (e.g., VPS or Raspberry Pi).

Where can I get help?

The main source of information is the documentation on this site. If you found a bug or have a suggestion — create an Issue on GitHub. Pull Requests are welcome.
