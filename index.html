Возможности

Всё в одном шаблоне

DSL v3.0 описывает весь сервер текстом. Без панелей, без кликов, без ботов-конкурентов.

Build

Загрузи .txt шаблон - бот построит сервер автоматически. Роли, каналы, права доступа - всё по одному файлу.

Export

Экспортируй текущую структуру сервера в DSL-формат для бэкапа или клонирования.

Sync

Синхронизация слеш-команд одной командой. Только для владельца сервера.

Roles & Permissions

Создавай роли с цветом, правами и отображением. Управление доступом через allow/deny по именам ролей.

Tickets

Встроенная тикет-система через кнопки. Автоматическое создание приватных каналов.

Temp Voice

Временные голосовые комнаты. Пользователи создают свои каналы - они удаляются когда все уходят.

Reaction & Button Roles

Роли по реакциям и кнопкам. Настраивай выдачу ролей в один клик.

Advanced DSL

INCLUDE, VAR, CATEGORY, FORUM, STAGE, COUNTER, AUTO_MESSAGE, WELCOME - полный набор блоков v3.0.

DSL Пример

Шаблон → Сервер

Один текстовый файл описывает роли, каналы, категории, форумы, тикеты, временные голосовые.

server.txt 
// server.txt - DSL v3.0
@name "My Server"

!INCLUDE "base.txt"

$color_main = #5865F2
$prefix = "!"

CATEGORY "Информация" {
  CHANNEL #📜-правила {
    @slowmode 5
  }
  CHANNEL #📢-новости
}

CATEGORY "Общение" {
  CHANNEL #общий
  CHANNEL #оффтоп
  FORUM "Поддержка" {
    THREAD баг-репорт
    THREAD вопрос
    THREAD предложение
  }
}

ROLE "Модератор" color=$color_main {
  @permissions kick_members, ban_members
  @display separate
}

TICKET "Связаться с нами" {
  @category "Поддержка"
  @button 📩 Создать тикет
}

TEMP_VOICE "Создать комнату" {
  @category "Голосовые"
  @button 🔈 Создать
}

Быстрый старт

Начни за 3 шага

От установки до первого готового сервера - меньше минуты.

01

Установка

Установи зависимости и настрой бота.

pip install -r requirements.txt
cp config.example.py config.py
02

Настройка

Открой config.py и вставь токен Discord-бота.

TOKEN = "your-bot-token-here"
03

Запуск

Запусти бота и загрузи шаблон сервера.

python main.py
# На сервере: /build
Команды

Просто и мощно

Три команды - полный контроль над сервером.

/build Загрузить .txt шаблон и построить сервер
/export Экспортировать сервер в DSL-формат
/sync Синхронизировать слеш-команды (владелец)
Настройка Discord

Создание бота

Зарегистрируй нового бота в Discord за пару минут. Всё делается в браузере, ничего устанавливать не нужно.

01

Создай приложение

Перейди на Discord Developer Portal и нажми "New Application". Введи название бота.

1. Открой https://discord.com/developers/applications
2. New Application → "DS Motier"
3. Сохрани Application ID
Discord Developer Portal →
02

Создай бота

В разделе Bot нажми "Add Bot". Включи нужные Gateway Intents.

Bot → Add Bot
✓ SERVER MEMBERS INTENT
✓ MESSAGE CONTENT INTENT
✓ PRESENCE INTENT
03

Скопируй токен

Нажми "Reset Token" и скопируй полученный токен. Этот токен нужен в config.py.

TOKEN = "скопированный-токен-бота"
04

Пригласи бота на сервер

В разделе OAuth2 → URL Generator выбери bot и административные права, затем открой сгенерированную ссылку.

Scopes: bot
Permissions: Administrator
→ Сгенерировать URL → Открыть
FAQ

Частые вопросы

Всё, что нужно знать перед началом.

Что такое DS Motier?

Discord-бот с открытым исходным кодом, который собирает структуру сервера по текстовому шаблону. Вместо ручного создания каждого канала и роли ты пишешь один .txt файл.

Нужен ли опыт программирования?

Нет. DSL - простой текстовый формат. Достаточно открыть блокнот и описать структуру. Примеры есть в документации.

Какие права нужны боту?

Боту необходимо право управлять сервером (administrator или manage channels + manage roles). Все действия выполняются через слеш-команды.

Можно ли обновить существующий сервер?

Да. Команда /build применит шаблон поверх текущей структуры: создаст недостающие каналы, обновит роли, но не тронет существующий контент.

Это бесплатно?

Да. Открытый исходный код под лицензией MIT. Ты можешь использовать, модифицировать и распространять бота без ограничений.
