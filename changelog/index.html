История версий

История изменений DS Motier от первого релиза до текущей версии.

v3.0.0
2026-05-20 Major Release - Полный редизайн DSL
  • ✦ Новый парсер DSL v3.0: полная переработка синтаксиса
  • ✦ Блок FORUM с вложенными THREAD
  • ✦ Блок STAGE для эфиров
  • ✦ Блок COUNTER - счётчики участников
  • ✦ TEMP_VOICE - временные голосовые комнаты
  • ✦ BUTTON_ROLE и REACTION_ROLE
  • ✦ AUTO_MESSAGE и WELCOME
  • ✦ Переменные VAR ($имя = значение)
  • ✦ Директива !INCLUDE для подключения файлов
  • ✦ Селекторы @allow / @deny для ролей и каналов
  • ⟳ Команды переведены на слеш-команды (/build, /export, /sync)
  • ⟳ Улучшена обработка ошибок в шаблоне
  • ● Исправлена проблема с кодировкой UTF-8 в Windows
  • ● Исправлена обработка пустых категорий
v2.0.0
2025-11-15 Major Release - Тикеты и роли
  • ✦ Тикет-система (блок TICKET)
  • ✦ Управление ролями через DSL (ROLE)
  • ✦ Поддержка прав доступа в каналах
  • ✦ Режим для голосовых каналов
  • ⟳ Улучшена валидация шаблонов
  • ● Исправлен экспорт сервера
v1.0.0
2025-07-01 Initial Release
  • ✦ Первый публичный релиз
  • ✦ Базовая сборка сервера по шаблону
  • ✦ Поддержка категорий и каналов
  • ✦ Команда /build
  • ✦ Команда /export
  • ✦ Команда /sync
