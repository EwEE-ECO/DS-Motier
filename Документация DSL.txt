# Discord Server DSL v3.0

## Цель

Discord Server DSL предназначен для полного описания Discord-сервера в текстовом формате.

DSL должен поддерживать:

* Сервер
* Роли
* Категории
* Текстовые каналы
* Голосовые каналы
* Форумы
* Stage-каналы
* Права доступа
* Автовыдачу ролей
* Тикеты
* Временные комнаты
* Счётчики участников
* Приветственные сообщения
* Логи
* Экспорт и импорт

---

# Базовые типы

## Строка

name = "General"

## Число

limit = 10

## Логическое значение

nsfw = true

---

# Переменные

VAR SERVER_NAME = "My Server"

Использование:

name = SERVER_NAME

---

INCLUDE "roles.dsl"

# Сервер

SERVER {
name = "My Community"
description = "Лучшее сообщество разработчиков"
verification_level = medium
default_notifications = all
}

---

# Роли

ROLE {
id = owner
name = "👑 Owner"
color = "#ff0000"

```
permissions = administrator
```

}

ИЛИ

ROLE {
id = moderator

```
permissions = manage_messages,kick_members,moderate_members
```

}

Поддерживаемые разрешения:

administrator
manage_channels
manage_roles
manage_messages
manage_threads
manage_events
kick_members
ban_members
moderate_members
mention_everyone
view_audit_log

---

# Категории

CATEGORY {
name = "Administration"
}

Права категории:

CATEGORY {

```
name = "Administration"

allow = owner,moderator
deny = member
```

}

Все дочерние каналы наследуют права.

# Welcome Message

WELCOME {

```
channel = "welcome"

message = "Добро пожаловать на сервер {user}!"
```

}

Переменные:

{user}
{username}
{member_count}
{server_name}

---

# Auto Role

AUTO_ROLE {

```
role = member
```

}

Выдаётся автоматически после входа.
